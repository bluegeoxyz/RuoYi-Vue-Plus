# V1.0 Migration 版本清单

## 管理结论

仓库没有可验证的 Flyway 历史表或 Flyway 运行配置；现阶段采用“受控手工 Migration Ledger + 仓库 SHA-256 清单”风险更低。不能把既有环境直接 `baselineOnMigrate`，否则会伪造历史。

- 新安装：先安装 RuoYi 核心库，再仅执行 `script/sql/zbm/baseline/` 当前基线；不得再执行 V2.0.1–V2.0.36。
- 存量升级：只按语义版本顺序执行尚未执行且已验证的增量脚本；`2.0.33.1` 位于 `2.0.33` 和 `2.0.34` 之间。
- 禁止混用 baseline 与增量、重复执行、伪造已执行记录、静默修改已执行脚本。
- Ledger 后续应记录环境、版本、文件名、校验值、执行人、开始/结束时间、结果和审批号；本任务未在正式库创建 Ledger 表。
- 可重复校验：`.\script\audit\Get-ZbmMigrationManifest.ps1`。脚本强制检查 37 个版本及边界。

## 4. 构建告警

- `ChargeBindingServiceImpl`、MCP/demo 代码使用 deprecated API。
- `LambdaQueryBuilder` 有 unchecked/unsafe 操作。
- `RoomVo`、`BuildingVo` 有 Lombok equals/hashCode superclass 告警。
- Mockito 动态加载 Byte Buddy agent，未来 JDK 默认行为会变化。
- 前端构建成功，但存在较大的 JS/CSS chunk，应作为性能治理项而非构建失败。

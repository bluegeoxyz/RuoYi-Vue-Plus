## 结论限制

- Maven 编译通过只证明当前代码可编译。
- 物业/仓储单测通过不证明浏览器端业务验收通过。
- SQL 文件存在不证明 WSL Docker MySQL 已应用该版本。
- 菜单 migration 存在不证明当前角色已正确获得菜单。

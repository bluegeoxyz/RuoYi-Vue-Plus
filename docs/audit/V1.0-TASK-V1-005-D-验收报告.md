## 未解决风险

1. 新库尚无最小物业项目/楼栋/房屋/收费/仓储业务夹具，无法在保持干净数据库的同时完成所有带业务状态的浏览器 E2E。
2. `log_bin_trust_function_creators=0` 时，普通测试账号即便拥有 schema 级 `TRIGGER` 权限也不能创建触发器；当前采用受控管理员临时开启并在 `finally` 等价流程中恢复，不能向业务账号授予全局 `SUPER`。
3. 应用回归产生的登录日志和系统消息属于新库运行痕迹，不是从旧库迁移的业务数据。
4. 本次没有删除旧库和恢复验证库；后续清理须单独获得授权。

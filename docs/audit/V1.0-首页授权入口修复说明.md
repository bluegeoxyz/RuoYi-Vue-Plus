# V1.0 首页授权入口修复说明

## 根因与修复

MIX 布局会在切换顶级菜单时把 `permissionStore.sidebarRouters` 替换为当前分区的子树，因此它不能用于首页全局授权判断。首页现改为读取登录后稳定保存的 `permissionStore.defaultRoutes`，并通过 `src/views/homeMenu.ts` 递归展开全量授权页面。

业务卡片使用明确路径域映射：

| 卡片 | 授权路由域 |
|---|---|
| 项目概况 | `/project` |
| 房屋与入住 | `/resource` |
| 业主与住户 | `/customer` |
| 收费管理 | `/charge` |
| 仓库库存 | `/warehouse` |

路径映射只证明页面入口存在，不替代按钮权限、业务操作权限、项目范围或仓库范围判断。项目上下文没有参与菜单入口识别。

## 验证

- 单元测试覆盖多级递归、局部侧栏变化、无授权入口与项目上下文无关性。
- SuperAdmin 首页五类卡片均为“已授权”；切换到仓库顶级菜单后留在首页，五类状态保持不变。
- 普通客服账号只显示客户、收费已授权；项目、资源、仓库为“暂无入口”。
- 仓储账号只显示仓库已授权，且没有物业项目选择器。

## 审计结论

- Java 版本为 21，后端端口为 8080，生产 Profile 为 `prod`。
- 生产前端 API 前缀为 `/prod-api`。
- 消息接口路径为 `/resource/message`，当前默认 SSE，代码同时支持 WebSocket。
- 数据库通过 `ZBM_DB_URL`、`ZBM_DB_USERNAME`、`ZBM_DB_PASSWORD` 注入；Compose 根据外部网络 DNS 生成 URL。
- Redis 使用 `ZBM_REDIS_HOST/PORT/DATABASE/PASSWORD`。
- Flyway 保持 V1 不变，并保持 validate、禁止自动 baseline、禁止 clean 的安全策略。

## 发布设计

JAR 和前端压缩包先进入 `incoming/<version>`，使用 SHA-256 校验后复制到临时 release 目录，最后原子替换 `current` 软链接。切换后只重建对应容器，以确保 Docker bind mount 解析到新版本。历史 release 保留，回滚不覆盖当前文件。

## 数据库保护

Compose 不声明 MySQL、Redis 服务或数据卷。本次没有执行数据库写入、迁移、清表、删除或旧库切换，也没有修改 Flyway V1。

构建、Compose 配置解析和容器验证结果记录在 `V1.0-TASK-V1-008-构建与容器验证报告.md`。没有目标服务器访问权限时，只能报告本地/WSL验证结果，不等同于服务器部署成功。

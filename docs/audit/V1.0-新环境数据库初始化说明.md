# V1.0 新环境数据库初始化说明

1. 创建专用空数据库和最小权限应用账号；确认库中没有任何业务表。
2. 配置 `ZBM_DB_URL`、`ZBM_DB_USERNAME`、`ZBM_DB_PASSWORD` 以及客户加密/HMAC、Redis 等环境变量。
3. 设置 `ZBM_FLYWAY_ENABLED=true` 后启动应用。Flyway 自动执行 `V1__initial_schema.sql`。
4. 检查日志包含 `Successfully validated 1 migration` 与 `Successfully applied 1 migration`。
5. 再次启动，必须显示 `Schema is up to date. No migration necessary.`。
6. 核对 59 张应用表、1 张 `flyway_schema_history`，并验证内置账号、角色、菜单、字典和客户端数据。

严禁对非空数据库直接执行上述流程；严禁将归档迁移目录加入扫描路径。生产凭据不得写入仓库。

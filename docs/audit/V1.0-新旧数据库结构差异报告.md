| 项目 | 结果 |
|---|---:|
| 保留表缺失/多余 | 0 / 0 |
| 字段类型、可空性、默认值、extra、collation 差异 | 0 |
| 索引/唯一约束差异 | 0 |
| CHECK 约束差异 | 0 |
| 预期排除对象 | `test_demo`, `test_tree` |
| V1 新增管理表 | `flyway_schema_history` |

初始化数据有意不同：开发库含 15 用户、12 角色、286 菜单及业务/日志数据；V1 仅含 1 用户、8 角色、270 个有效菜单和必要字典配置。验证库不含开发业务数据，也不存在 `flow_*`、`sj_*`、Demo 表。

开发库仍为 61 张表且不存在 `flyway_schema_history`，本阶段未修改其结构、数据或版本状态。

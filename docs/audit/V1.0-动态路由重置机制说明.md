# V1.0 动态路由重置机制说明

## 机制

`src/router/dynamicRouteRegistry.ts` 统一管理本地权限路由和后端动态路由：

1. 调用 Vue Router `addRoute` 时保存其 remove 回调，并递归记录路由名称。
2. 新一轮注册前先逆序移除上一账号路由，避免重复注册。
3. 注销时移除全部动态路由并清空 permission store 的全量、顶栏、侧栏和新增路由状态。
4. 每次路由请求获得版本号；注销会使在途请求版本失效，旧请求返回后不能再写入 store 或注册路由。
5. user store 在登录成功建立新会话前、正常注销、token 失效调用注销路径时，统一清理角色、权限、用户身份、项目上下文、tagsView、缓存视图和 iframe 导航状态。

`src/permission.ts` 不再重复调用 `router.addRoute`；动态路由注册由 permission store 单点负责。

## 浏览器证据

- SuperAdmin 可打开 `/warehouse/base/warehouse`，刷新后页面仍可恢复。
- 同一 SPA 会话注销并登录普通客服账号后，旧重定向进入该 URL 显示前端 404，证明旧动态路由已经移除。
- 普通客服注销后重新登录 SuperAdmin，全量业务入口重新恢复。
- 仓储账号可独立进入仓库页面，不继承物业入口。

后端权限仍是最终授权边界，本机制没有修改后端校验。

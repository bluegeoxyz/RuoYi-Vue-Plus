# TASK-V1-007 E2 项目上下文与 IDOR 验收报告

## 结论

项目工作区初始化与动态路由隔离的真实浏览器主场景 **通过**；跨项目列表、详情、编辑、导出的逐接口浏览器复核未全部执行，相关 IDOR 结论同时引用 Admin HTTP 与物业服务测试。

## 浏览器证据

- `e2e_customer`：登录后自动选择 `E2E-A`，首页明确显示当前项目；无项目切换器。
- `e2e_multi`：初始不擅自选择，1280px 下选择器列出且仅列出 `E2E-A`、`E2E-B`；选择 B 后首页显示“当前项目：E2E-B”。
- `e2e_warehouse`：无需物业项目即可进入 `/warehouse/base/warehouse`，首页物业卡片均“暂无入口”。
- 账号切换后旧账号路由不可访问，未授权直链进入 404。

## 自动化补充证据

- Admin HTTP：75 项全部执行且通过，包含跨项目关系访问、导入范围和撤权即时生效。
- 物业模块：280 项全部执行且通过，包含 `PropertyProjectScopeService`、工作区策略、项目业务动作和数据库约束测试。
- 权限契约：backend 166 / frontend 131 / menu 169；关键菜单缺失集合为空。

## 未完全覆盖

未逐一用浏览器 Network 记录跨项目列表、详情、编辑和导出的 HTTP 状态码；因此这些细项标记为“自动化通过、浏览器未逐项复核”。

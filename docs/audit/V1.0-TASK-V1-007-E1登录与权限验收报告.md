E1 **通过**。浏览器使用真实前端、真实后端和 `zbm_dev_v1`。为避免自动化求解验证码，本地验收进程仅以启动参数 `--captcha.enable=false` 关闭验证码；账号密码、Sa-Token、菜单接口、动态路由和后端授权均为真实链路。

# V1.0 数据库基线说明

唯一权威新装迁移是 `ruoyi-admin/src/main/resources/db/migration/V1__initial_schema.sql`，SHA-256 为 `a55ed720dd5cbd504b9e5ac88d8e4aa6ddd6390f837c4fd15b1154cdb130f9e6`。文件由 `script/audit/New-ZbmV1Baseline.ps1` 从只读 `zbm-data` 结构和经过筛选的必要种子数据生成；旧 `script/sql/zbm/baseline/` 仅为历史开发参考，不是第二套权威源，也不得用于新环境。

V1 面向 MySQL 8.0，包含 59 张保留应用表、现有字段/索引/CHECK 约束、明确的 `utf8mb4` 定义和必要基础数据。它不包含 `test_demo`、`test_tree`，不包含真实业务单据、测试项目/客户/库存、运行日志、消息、OSS 凭据或数据库账号。

V1 发布后不得修改。后续结构或初始化数据变化从 `V2__*.sql` 开始追加；结构快照必须从 Flyway 初始化后的空库自动导出，不维护人工同步副本。
